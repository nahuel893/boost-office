LEGEND
------
  +--------+
  | ICON   |    L  LARGE button: 32 px icon, label below          (json style "large")
  +--------+
  (x) Label     S  SMALL button: 16 px icon, label to the right   ("small-label")
  (x)           I  SMALL button: icon only, tooltip = the name    ("small")
  v             DROPDOWN: the whole button opens a menu
  |v            SPLIT: the body runs an action, the arrow opens a menu
  [P]           PLACEHOLDER: greyed out until the feature is implemented

  Columns of the control tables:
    #, pos      order on the tab; c<column>r<row> inside the section
    Excel       Excel's control, size (L/S/I) and kind (btn, tgl, chk, dd, split, combo, spin)
    here        size and kind on our ribbon (dd = dropdown, tgl = toggle shown pressed;
                checkboxes become toggle buttons: gen_ribbon only makes tool buttons)
    kind        existing   LibreOffice command used as is (LibreOffice's own label)
                variant    existing command with URL arguments (".uno:X?Arg:type=v"), with its
                           own label/tooltip node in CalcCommands.xcu; config only, no new slot
                NEW DD     new dropdown command: CalcCommands.xcu label, Controller.xcu Popup +
                           ToolBox (GenericPopupToolbarController) nodes, popup xml; no slot
                NEW SPLIT  new body slot (Data recipe, same Execute/state as the original) +
                           new "...Menu" popup command opened by the arrow
                NEW ALIAS  new slot that mirrors an existing slot only to carry Excel's label
                PLACEHOLDER always-disabled slot (Data recipe); a "family slot" is one slot shared
                           by several URL variants ".uno:Base?Arg:string=value", each with its own
                           label and tooltip (see the overview: the slot budget forces this)
                "slot +N" = SID_NEW_SLOTS+N in sc/inc/sc.hrc (allocation table in the overview)
    label       text on the button: LibreOffice's "Label" without "~" and "..." for existing
                commands (as on the Data tab), Excel's label for new commands
    icon        B boost icon exists; A alias of an existing boost icon (no new art);
                C Colibre icon exists and shows today, boost icon to add for consistency;
                N no icon anywhere, boost icon required before the tab ships.
                Then the Fluent 1.1.344 glyph (every name checked in
                /mnt/games/libreoffice/assets/fluent/package/icons/).
    json id     for URL variants the json "cmd" is a short id and "action" holds the URL;
                the icon comes from the item's "icon" key (e.g. "cmd/32/insertcharttype_map.png",
                boost manifest name "<base>_<value>"), which avoids the escaped "%3f" file names.

  Restart in Troubleshoot Mode, Donate, License Information, About. The menu button at the top
  right (popupmenu/notebookbar.xml) keeps Help, Donate and About; the File tab keeps its Help
  button.
