===================================================================
Status: DESIGN for task T4; the implementer follows this file verbatim. Nothing built yet.
Date: 2026-10-15. Reference: Excel for Microsoft 365, Windows, 2024+ look, window 1920 px:
product/docs/research/2026-10-15-excel365-ribbon-reference.md section 3; images in
/mnt/games/libreoffice/assets/excel-ref/formulas/ (never committed).
Same tools and rules as product/docs/design/calc-data-tab-layout.txt: gen_ribbon.py layout,
Fluent "boost" icons, compact rows. Every Excel control is on the tab, in Excel's order: an
existing LibreOffice command, a new dropdown/split command, or a greyed PLACEHOLDER (a real
always-disabled slot, label = Excel label, tooltip "<Label> (not available yet)").
Every .uno: command named here was checked against CalcCommands.xcu / GenericCommands.xcu and
sc/sdi + svx/sdi + sfx2/sdi (exists, and a Calc shell implements it) unless marked "verify".
Ground truth: the 2024+ per-group crops formulas-bettersolutions-1..6.png; formulas-exceldemy-1.png
(2023, narrow) shows Excel's reduced forms. This page replaces LibreOffice's "Functions" tab
(page id phbFunctions kept); T1 renames it "Formulas" and moves it before Data.
Supersedes product/odd/tasks/calc-formulas-tab.md (feature ruling).

LEGEND
------
  +--------+
  | ICON   |    L  LARGE button: 32 px icon, label below          (json style "large")
  +--------+
  (x) Label     S  SMALL button: 16 px icon, label to the right   ("small-label")
  (x)           I  SMALL button: icon only, tooltip = the name    ("small")
  v             DROPDOWN: the whole button opens a menu
  |v            SPLIT: the body runs an action, the arrow opens a menu
  [P]           PLACEHOLDER: greyed out until the feature is implemented

  Columns of the control tables:
    #, pos      order on the tab; c<column>r<row> inside the section
    Excel       Excel's control, size (L/S/I) and kind (btn, tgl, chk, dd, split, combo, spin)
    here        size and kind on our ribbon (dd = dropdown, tgl = toggle shown pressed;
                checkboxes become toggle buttons: gen_ribbon only makes tool buttons)
    kind        existing   LibreOffice command used as is (LibreOffice's own label)
                variant    existing command with URL arguments (".uno:X?Arg:type=v"), with its
                           own label/tooltip node in CalcCommands.xcu; config only, no new slot
                NEW DD     new dropdown command: CalcCommands.xcu label, Controller.xcu Popup +
                           ToolBox (GenericPopupToolbarController) nodes, popup xml; no slot
                NEW SPLIT  new body slot (Data recipe, same Execute/state as the original) +
                           new "...Menu" popup command opened by the arrow
                NEW ALIAS  new slot that mirrors an existing slot only to carry Excel's label
                PLACEHOLDER always-disabled slot (Data recipe); a "family slot" is one slot shared
                           by several URL variants ".uno:Base?Arg:string=value", each with its own
                           label and tooltip (see the overview: the slot budget forces this)
                "slot +N" = SID_NEW_SLOTS+N in sc/inc/sc.hrc (allocation table in the overview)
    label       text on the button: LibreOffice's "Label" without "~" and "..." for existing
                commands (as on the Data tab), Excel's label for new commands
    icon        B boost icon exists; A alias of an existing boost icon (no new art);
                C Colibre icon exists and shows today, boost icon to add for consistency;
                N no icon anywhere, boost icon required before the tab ships.
                Then the Fluent 1.1.344 glyph (every name checked in
                /mnt/games/libreoffice/assets/fluent/package/icons/).
    json id     for URL variants the json "cmd" is a short id and "action" holds the URL;
                the icon comes from the item's "icon" key (e.g. "cmd/32/insertcharttype_map.png",
                boost manifest name "<base>_<value>"), which avoids the escaped "%3f" file names.

  Notes
  - Insert Function -> .uno:FunctionDialog (LibreOffice's Function Wizard, label "Function").
  - AutoSum |v: NEW SPLIT. Body .uno:FormulasAutoSum, slot SID_NEW_SLOTS+15 (FID_FORMULAS_AUTOSUM),
    same Execute as SID_AUTO_SUM (cellsh.sdi:296 ExecuteEdit, cellsh1.cxx:3247); SID_AUTO_SUM has
    no StateMethod, so the mirror has none and needs no invalidation mirror. Arrow: popup command
    .uno:FormulasAutoSumMenu. The menu items are URL variants of .uno:AutoSum: verified,
    cellsh1.cxx:3250 reads the "Function" string argument and accepts "average", "count", "min",
    "max" (locale independent). Labels "Average", "Count Numbers", "Max", "Min" go in
    CalcCommands.xcu; "Sum" is .uno:AutoSum's own label. The body icon is an alias of the boost
    "autosum" icon (manifest "aliases"). Home > Editing > AutoSum stays a plain button (Home slice).
  - Recently Used, Financial, Logical, Text, Date & Time, Lookup & Reference, Math & Trig, More
    Functions: eight NEW DROPDOWNS whose menus are filled at run time by ONE new C++ popup menu
    controller (a PopupMenuController registered in Controller.xcu Popup nodes for the eight
    commands; the category comes from the command name). This is the only sizeable C++ of the
    slice. It reads ScGlobal::GetStarCalcFunctionMgr() (category ids in sc/inc/scfuncs.hxx:
    1 Database, 2 Date&Time, 3 Financial, 4 Information, 5 Logical, 6 Mathematical, 7 Array,
    8 Statistical, 9 Spreadsheet, 10 Text, 11 Add-in) and, for Recently Used, the LRU list of
    ScAppOptions. Each item dispatches
        .uno:InsertFunction?FunctionName:string=<NAME>&FunctionCategory:short=0
    verified: SID_INS_FUNCTION (scalc.sdi:3252, cellsh1.cxx:2147) starts input mode and inserts
    "=NAME(arg names)" into the cell, exactly what the Functions sidebar does. Category 0 is the
    "all functions" list, and the controller passes the localized name it got from the function
    manager, so the lookup works in every UI language. The last item of each menu is
    "Function..." (.uno:FunctionDialog, Excel's "Insert Function..."). Mapping: Lookup &
    Reference = LibreOffice "Spreadsheet" (9); Math & Trig = "Mathematical" (6). More Functions has
    submenus Statistical (8), Engineering (LibreOffice "Add-in", 11: the Analysis add-in), Information
    (4), plus LibreOffice extras Database (1) and Array (7); Excel's Cube, Compatibility and Web
    submenus are omitted (no LibreOffice category).
    Config-only fallback if T4 cannot take the C++: each dropdown gets a static popup xml with
    "Function..." (.uno:FunctionDialog) and "Function List" (.uno:FunctionBox); still no slot.
