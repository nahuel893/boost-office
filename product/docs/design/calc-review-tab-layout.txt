Date: 2026-10-15. Reference: Excel for Microsoft 365, Windows, 2024+ look, window 1920 px:

Same tools and rules as product/docs/design/calc-data-tab-layout.txt: gen_ribbon.py layout,
Fluent "boost" icons, compact rows. Every Excel control is on the tab, in Excel's order: an
existing LibreOffice command, a new dropdown/split command, or a greyed PLACEHOLDER (a real
always-disabled slot, label = Excel label, tooltip "<Label> (not available yet)").
Every .uno: command named here was checked against CalcCommands.xcu / GenericCommands.xcu and
sc/sdi + svx/sdi + sfx2/sdi (exists, and a Calc shell implements it) unless marked "verify".
Ground truth: review-exceldemy-1.png (2023, full tab) and the 2024+ crops
review-bettersolutions-1..8.png; review-mssupport-1.png is probably Excel for the web.

LEGEND
------
  +--------+
  | ICON   |    L  LARGE button: 32 px icon, label below          (json style "large")
  +--------+
  (x) Label     S  SMALL button: 16 px icon, label to the right   ("small-label")
  (x)           I  SMALL button: icon only, tooltip = the name    ("small")
  v             DROPDOWN: the whole button opens a menu
  |v            SPLIT: the body runs an action, the arrow opens a menu
  [P]           PLACEHOLDER: greyed out until the feature is implemented

  Columns of the control tables:
    #, pos      order on the tab; c<column>r<row> inside the section
    Excel       Excel's control, size (L/S/I) and kind (btn, tgl, chk, dd, split, combo, spin)
    here        size and kind on our ribbon (dd = dropdown, tgl = toggle shown pressed;
                checkboxes become toggle buttons: gen_ribbon only makes tool buttons)
    kind        existing   LibreOffice command used as is (LibreOffice's own label)
                variant    existing command with URL arguments (".uno:X?Arg:type=v"), with its
                           own label/tooltip node in CalcCommands.xcu; config only, no new slot
                NEW DD     new dropdown command: CalcCommands.xcu label, Controller.xcu Popup +
                           ToolBox (GenericPopupToolbarController) nodes, popup xml; no slot
                NEW SPLIT  new body slot (Data recipe, same Execute/state as the original) +
                           new "...Menu" popup command opened by the arrow
                NEW ALIAS  new slot that mirrors an existing slot only to carry Excel's label
                PLACEHOLDER always-disabled slot (Data recipe); a "family slot" is one slot shared
                           by several URL variants ".uno:Base?Arg:string=value", each with its own
                           label and tooltip (see the overview: the slot budget forces this)
                "slot +N" = SID_NEW_SLOTS+N in sc/inc/sc.hrc (allocation table in the overview)
    label       text on the button: LibreOffice's "Label" without "~" and "..." for existing
                commands (as on the Data tab), Excel's label for new commands
    icon        B boost icon exists; A alias of an existing boost icon (no new art);
                C Colibre icon exists and shows today, boost icon to add for consistency;
                N no icon anywhere, boost icon required before the tab ships.
                Then the Fluent 1.1.344 glyph (every name checked in
                /mnt/games/libreoffice/assets/fluent/package/icons/).
    json id     for URL variants the json "cmd" is a short id and "action" holds the URL;
                the icon comes from the item's "icon" key (e.g. "cmd/32/insertcharttype_map.png",
                boost manifest name "<base>_<value>"), which avoids the escaped "%3f" file names.

LAYOUT FILE
-----------
  product/ui/calc_review.json: page "phbReview", id_prefix "Review", context "TabbedCalc",
  remove_objects ["Menu Review"].
  The upstream sections Spelling, Comments, Track Changes, Document and the
  "Review-ReviewButton:Menu Review" overflow button are replaced; "Menu Review" is removed.

  COMMENTS AND NOTES. Excel has threaded "comments" (Comments group) and legacy "notes" (Notes
  menu). LibreOffice has one kind, called comments, that behaves like Excel's notes (yellow box,
  shown/hidden per cell; written to .xlsx as notes). Both Excel controls therefore drive the same
  LibreOffice comments: the Comments group has the everyday buttons, the Notes menu the
  note-style actions (show/hide one, show/hide all, delete all). Previous/Next are one family
  placeholder used in both places. Convert to Comments is omitted (only one kind exists).
  Sections (json name / caption / rows / estimated width at 1920 px):
    Proofing        Proofing            rows 3   ~207 px
    Accessibility   Accessibility       rows 3   ~137 px
    Language        Language            rows 3   ~71 px
    Comments        Comments            rows 3   ~510 px
    Notes           Notes               rows 3   ~65 px
    Protect         Protect             rows 3   ~509 px
    Ink             Ink                 rows 3   ~66 px
                    total                        ~1564 px  (budget ~1875 px, see FIT PLAN)

    Accessibility Options and Accessibility Help are omitted.

SECTION 4 - COMMENTS
--------------------
  +---------+ +----------------+ +------------------+ +--------------+ +---------------+
  | Comment | | Delete Comment | | Previous Comment | | Next Comment | | Show Comments |
  +---------+ +----------------+ +-------[P]--------+ +-----[P]------+ +---------------+

  #  pos   Excel control (size, kind)                   here     kind        label shown
  1  c1    New Comment (L, btn)                         L btn    existing    "Comment"
       .uno:InsertAnnotation
       icon C comment_add
  2  c2    Delete (L, btn)                              L btn    existing    "Delete Comment"
       .uno:DeleteNote
       icon C comment_dismiss
  3  c3    Previous Comment (L, btn)                    L btn    PLACEHOLDER "Previous Comment"
       .uno:ReviewGoToComment?Direction:string=previous   [family slot +410 FID_REVIEW_GOTO_COMMENT]
       icon N comment_arrow_left   json id CommentPrevious
  4  c4    Next Comment (L, btn)                        L btn    PLACEHOLDER "Next Comment"
       .uno:ReviewGoToComment?Direction:string=next   [family slot +410 FID_REVIEW_GOTO_COMMENT]
       icon N comment_arrow_right   json id CommentNext
  5  c5    Show Comments (L, tgl)                       L tgl    existing    "Show Comments"
       .uno:ShowAnnotations
       icon C comment_multiple

  Notes
  - New Comment -> .uno:InsertAnnotation ("Comment"); Delete -> .uno:DeleteNote ("Delete Comment",
    enabled when the cell has a comment); Show Comments -> .uno:ShowAnnotations (label "Show
    Comments": shows or hides all comments of the selected sheets, cellsh1.cxx:2873; disabled
    when the sheet has none. Excel opens a Comments pane, which LibreOffice lacks).
  - Previous Comment / Next Comment: family placeholder .uno:ReviewGoToComment?Direction:string=
    previous|next (SID_NEW_SLOTS+410). LibreOffice has no "go to next comment" command; the
    Navigator lists comments.

  Notes
  - Protect Workbook -> .uno:ToolProtectionDocument ("Protect Spreadsheet Structure", a toggle like
    Excel's).
  - Allow Edit Ranges: placeholder (+411). LibreOffice protects cells per style/format, with no
    per-range passwords.
  - Unshare Workbook -> .uno:ShareDocument ("Share Spreadsheet"): LibreOffice's shared
    spreadsheet IS Excel's legacy shared workbook, and its dialog turns sharing on and off. Excel's
    button is disabled unless the workbook is shared; LibreOffice's is enabled (it opens the dialog).

1920 PX FIT PLAN
----------------
  About 1564 px of the ~1875 px budget: every group full size, about 310 px to spare (the three
  omitted groups are what makes Excel itself tight here). If translations need room, Excel's
  reduced forms apply: Proofing as one S column, then Previous / Next / Show Comments icon-only.

OPEN QUESTIONS
--------------
  1. Comments and Notes both drive LibreOffice's single comment type (design above). Alternative:
     treat Excel's threaded comments as five placeholders and put all LibreOffice comment
     commands under Notes (more exact, but the main Comment buttons would be greyed).
  2. Translate: placeholder (current) or omitted as a Microsoft cloud service?
  3. Track Changes leaves the ribbon (as in Excel 365). LibreOffice users may miss it; it could
     go into the Notes menu or stay reachable only from the menu bar.
