CALC - HOME TAB REDESIGN (vertical slice 1)
==========================================
Status: section 1 (layout) APPROVED by the user on 2026-10-12.
Reference: Microsoft 365 Excel organization + compact own identity (WPS-like).
Key principle: every tab is split into SECTIONS with a visible title.


LEGEND
------
  +--------+
  | ICON   |    LARGE button: 32 px icon, label below
  +--------+
  (x) Label     SMALL button: 16 px icon, label to the right
  (x)           SMALL button: icon only (tooltip shows the name)
  [Text    v]   COMBO box (font name, size, number format)
  v             the button has a DROPDOWN menu
  ~             depends on a dropdown that may need C++ (verified during planning;
                if it does, it moves to stage B and stage A uses the fallback)

CHANGES AFTER APPROVAL (2026-10-12, matched against the user's Excel 365 web screenshot)
--------------------------------------------------------------------------------------

  - Font keeps Strikeout (S): Excel 365 shows it on Home.
  - Styles adds Format as Table (.uno:AutoFormat, LARGE), as in Excel 365.
  - Editing: AutoSum is a small labelled button stacked with Fill v and Clear v, as in
    Excel; Sort & Filter and Find & Select stay LARGE.
  - Number uses the original "0.0" button (.uno:NumberFormatDecimal: thousands separator
    + 2 decimals = Excel's Comma Style) instead of .uno:NumberFormatThousands.
  - Undo section kept although Undo/Redo also sit in the quick access bar (user decision).
  - Not added: Excel's Orientation v (no single LibreOffice command; stage B candidate).
