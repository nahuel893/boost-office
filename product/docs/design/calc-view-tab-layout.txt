CALC - VIEW TAB LAYOUT (Tabbed Office, remaining tabs, task L1)
===============================================================
Status: DESIGN for task T6; the implementer follows this file verbatim. Nothing built yet.
Date: 2026-10-15. Reference: Excel for Microsoft 365, Windows, 2024+ look, window 1920 px:
product/docs/research/2026-10-15-excel365-ribbon-reference.md section 5; images in
/mnt/games/libreoffice/assets/excel-ref/view/ (never committed).
Same tools and rules as product/docs/design/calc-data-tab-layout.txt: gen_ribbon.py layout,
Fluent "boost" icons, compact rows. Every Excel control is on the tab, in Excel's order: an
existing LibreOffice command, a new dropdown/split command, or a greyed PLACEHOLDER (a real
always-disabled slot, label = Excel label, tooltip "<Label> (not available yet)").
Every .uno: command named here was checked against CalcCommands.xcu / GenericCommands.xcu and
sc/sdi + svx/sdi + sfx2/sdi (exists, and a Calc shell implements it) unless marked "verify".
Ground truth: view-msqa-1.png (2025 user screenshot: Sheet View, Workbook Views, Show),
view-mstechcommunity-1..3.png (Show with Navigation and Focus Cell, Dark Mode group) and the
2024+ crops view-bettersolutions-1..6.png (Zoom, Window, Macros).

LEGEND
------
  +--------+
  | ICON   |    L  LARGE button: 32 px icon, label below          (json style "large")
  +--------+
  (x) Label     S  SMALL button: 16 px icon, label to the right   ("small-label")
  (x)           I  SMALL button: icon only, tooltip = the name    ("small")
  v             DROPDOWN: the whole button opens a menu
  |v            SPLIT: the body runs an action, the arrow opens a menu
  [P]           PLACEHOLDER: greyed out until the feature is implemented

  Columns of the control tables:
    #, pos      order on the tab; c<column>r<row> inside the section
    Excel       Excel's control, size (L/S/I) and kind (btn, tgl, chk, dd, split, combo, spin)
    here        size and kind on our ribbon (dd = dropdown, tgl = toggle shown pressed;
                checkboxes become toggle buttons: gen_ribbon only makes tool buttons)
    kind        existing   LibreOffice command used as is (LibreOffice's own label)
                variant    existing command with URL arguments (".uno:X?Arg:type=v"), with its
                           own label/tooltip node in CalcCommands.xcu; config only, no new slot
                NEW DD     new dropdown command: CalcCommands.xcu label, Controller.xcu Popup +
                           ToolBox (GenericPopupToolbarController) nodes, popup xml; no slot
                NEW SPLIT  new body slot (Data recipe, same Execute/state as the original) +
                           new "...Menu" popup command opened by the arrow
                NEW ALIAS  new slot that mirrors an existing slot only to carry Excel's label
                PLACEHOLDER always-disabled slot (Data recipe); a "family slot" is one slot shared
                           by several URL variants ".uno:Base?Arg:string=value", each with its own
                           label and tooltip (see the overview: the slot budget forces this)
                "slot +N" = SID_NEW_SLOTS+N in sc/inc/sc.hrc (allocation table in the overview)
    label       text on the button: LibreOffice's "Label" without "~" and "..." for existing
                commands (as on the Data tab), Excel's label for new commands
    icon        B boost icon exists; A alias of an existing boost icon (no new art);
                C Colibre icon exists and shows today, boost icon to add for consistency;
                N no icon anywhere, boost icon required before the tab ships.
                Then the Fluent 1.1.344 glyph (every name checked in
                /mnt/games/libreoffice/assets/fluent/package/icons/).
    json id     for URL variants the json "cmd" is a short id and "action" holds the URL;
                the icon comes from the item's "icon" key (e.g. "cmd/32/insertcharttype_map.png",
                boost manifest name "<base>_<value>"), which avoids the escaped "%3f" file names.

1920 PX FIT PLAN
----------------
  About 1672 px of the ~1875 px budget, every group full size, about 200 px to spare. Without the
  omitted Sheet View group (~320 px in Excel) there is no pressure. If needed later: Excel's
  reduced forms (Workbook Views: Page Layout and Custom Views as an S column; Window: New Window,
  Arrange All, Freeze Panes as an S column, small columns icon-only).

OPEN QUESTIONS
--------------
  1. Sheet View: omitted by the cloud ruling, but it is the first group of every default Excel
     View tab (shown greyed for local files). To match the look it could be greyed placeholders
     on one family slot (a "Default" view button instead of the combo, which gen_ribbon cannot
     make, plus Keep, Exit, New, Options). At full size (~270 px) the tab would overflow
     (~1940 px); with Excel's reduced form (four icon-only buttons, ~170 px) it fits (~1840 px).
  2. Dark Mode group: kept (LibreOffice command exists, product has dark mode) although Excel
     shows it only with the Black theme.
  3. Data Type Icons: omitted (cloud). A greyed placeholder would complete Excel's 2 x 3 grid.
