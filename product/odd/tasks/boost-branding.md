- **Status:** done, 2026-10-26 (published: https://github.com/nahuel893/boost-office/releases/tag/v0.1.1).
- **Locator:** `product/odd/tasks/boost-branding.md`

- **Repo / branch:** `/mnt/games/libreoffice/core`, branch `feature/boost-branding` from `main` (410ae2d47).

## Objective

Boost Office looks like Boost Office from the first frame: the splash screen, the About dialog and the window titles
show the Boost brand, not "LibreOffice Development Build" / "LibreOfficeDev". The user gets it with the same
one-command install (re-running it upgrades in place).

## Problem and why

The user (2026-10-26) installed 0.1.0 on their PC: "cuando lo abro me sale el logo de libre office que dice development
build". Cause: `instdir/program/intro.png` (and `intro-highres.png`) are copied from
`icon-themes/colibre/brand_dev/` because the build is not a release build; `program/shell/{about,logo,logo_inverted,
logo-sc,logo-sc_inverted}.svg` carry the LibreOfficeDev brand; `sofficerc` has `Logo=1`. The product name comes from
`/org.openoffice.Setup/Product/ooName` (`officecfg/registry/data/org/openoffice/Setup.xcu:22`), which a configuration
layer can override at runtime with no rebuild. LibreOffice's trademark policy also expects forks to carry their own
brand.

## Rulings (controller, 2026-10-26; the user asked for no questions and no review stops)

1. **No rebuild.** Branding is applied at install time and in the dev launcher, not by `configure --with-branding` or a
   full rebuild: brand images are an overlay the installer copies into `<prefix>/program/` and
   `<prefix>/program/shell/`; the product name is a configuration item.
2. **Splash:** keep a splash (Office apps show one): a Boost Office wordmark (Inter, from the shipped fonts) on the
   light workspace color from `palette.json`, a neutral progress bar, same pixel sizes as the stock `intro.png` and
   `intro-highres.png`; `sofficerc` progress settings adjusted to the new image if needed. Sources are SVG under
   `product/brand/`, PNGs generated by a script (like the icon zips: prebuilt into the release archive, so the user
   needs no converter).
3. **Logos:** `about.svg`, `logo.svg`, `logo_inverted.svg`, `logo-sc.svg`, `logo-sc_inverted.svg` replaced by Boost
   versions with the stock sizes (viewBox/width/height), so the About dialog and any Start Center logo show Boost.
4. **Product name:** `ooName` = `Boost Office` in the shared presets (`product/dev/profile.py` `build_items`, so it reaches
   both `boost.xcd` and the dev profile). Docs that say "LibreOfficeDev > Appearance" follow. What still says
   LibreOffice(Dev) after this (compile-time strings) is listed, not fixed.
5. **Release 0.1.1:** built with `product/release/make-release.sh` from the current `core/instdir` (it includes the Start
   Center redesign), published the way 0.1.0 was; re-running the one-liner upgrades an existing 0.1.0. The portable
   build (older glibc) moves to 0.2.0.
