# Inter

An open font by Rasmus Andersson, designed for user interfaces. Bundled here for the UI font trial
(`product/docs/ui-font-trial.md`).

- Source: https://github.com/rsms/inter, release v4.1 (`Inter-4.1.zip`, `extras/ttf/`).
- Version: 4.1 (font revision 4.001).
- Files: four static TrueType fonts, unmodified: `Inter-Regular.ttf`, `Inter-Medium.ttf`,
  `Inter-SemiBold.ttf` and `Inter-Bold.ttf`. The static fonts are used instead of the variable
  font because VCL's variable-font support is limited.
- License: SIL Open Font License 1.1, in `OFL.txt` (the release's `LICENSE.txt`).
