# Selawik

An open font by Microsoft, made as an open replacement for Segoe UI (upstream notes that it still
lacks Segoe UI's kerning and needs better hinting). Bundled here for the UI font trial
(`product/docs/ui-font-trial.md`).

- Source: https://github.com/microsoft/Selawik, release 1.01 (`Selawik_Release.zip`).
- Version: 1.01 (font revision 1.01).
- Files: the five static TrueType fonts, unmodified: `selawksl.ttf` (Semilight), `selawkl.ttf`
  (Light), `selawk.ttf` (Regular), `selawksb.ttf` (Semibold) and `selawkb.ttf` (Bold).
- License: SIL Open Font License 1.1, in `OFL.txt` (the repository's `LICENSE.txt`, with one
  trailing space removed). "Selawik" is a Reserved Font Name: a modified version must use
  another name.
